# Apartment-Recommendation-System
Group project for a lab course. A group project for a laboratory course that uses multi-objective optimization and fitness algorithms to recommend apartments near the University of Tsukuba. The system evaluates apartments based on rent, room size, distance to campus and Tsukuba Station, supermarket accessibility, and building age. Users can customize their budget, minimum room size, and criteria weights to generate recommendations tailored to their preferences.

Data is used from real apartments. 72 real apartment listings from
